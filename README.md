# 情報ネットワーク 練習問題

第1〜3回、第4回、第5回と第1〜6回の100問練習問題のMicrosoft Forms問題、および第6回の講義資料をもとにした計227問の静的Webアプリです。暗記カードと選択テストで復習でき、複数選択問題と図付き問題にも対応しています。

第5回の「BPDUフィルタが有効な access ポートに BPDU が到着するとどうなるか」という問題は、Formsで正解キーが設定されておらず、設定方法も書かれていません。ポート単位で有効にしたケースと解釈して「BPDUを破棄してポートは通常動作」を正解として補い、設定が曖昧な点を解説に記載しています。

## 起動

```sh
python3 -m http.server 8000
```

ブラウザーで `http://127.0.0.1:8000` を開きます。

## 学習方法

- **暗記カード**: 問題を考えてから答えを表示し、「もう一度」「迷った」「覚えた」で仕分けます。未習得の問題は同じ周回で再び出題されます。
- **選択テスト**: 選択肢を選んで答え合わせをします。Formsに図や解説がある問題では、それらも表示します。
- **範囲**: Formsの第1〜3回、第4回、第5回、第1〜6回の100問と、PDFをもとに作成した第6回を選べます。「要復習」「苦手優先」も使えます。

学習履歴はブラウザーの `localStorage` に保存されます。別のブラウザーや端末とは共有されません。

## 問題データ

`data/vocab.json` の `tests[].questions[]` に問題を追加します。1つ選ぶ問題は `answer` に選択肢のいずれかを設定し、複数選択問題は正解の選択肢を `answers` 配列に設定します。`source_page` にPDFのページ、`image_path` に図の相対パス、`explanation` に答え合わせで表示する解説を記載できます。出題範囲の見出しは `tests[].title` です。

```json
{
  "number": 1,
  "prompt": "通信手順やデータ構成を定める取り決めは？",
  "choices": ["プロトコル", "トポロジ", "インターフェース", "リンク"],
  "answer": "プロトコル",
  "explanation": "通信プロトコルは、通信手順やデータ形式を定めます。",
  "answer_language": "ja"
}
```

複数選択問題は、`answer` の代わりに `answers` 配列を使います。図を表示する場合は `image_path` に `data/` からの相対パスを指定します。

## GitHub Pages

`main` ブランチへのpushまたはActionsの手動実行で、GitHub Pagesへデプロイするワークフローを含みます。初回公開時はGitHubリポジトリのSettings → Pagesで、SourceをGitHub Actionsに設定してください。
